1. What class should implement the Comparable interface?
The Media class should implement the Comparable<Media> interface. This is because we want all subclasses of Media (e.g., Book, DigitalVideoDisc, CompactDisc) to inherit the default comparison behavior, so they can be sorted in a consistent way when using Collections.sort().

2. In those classes, how should you implement the compareTo() method to reflect the ordering that we want?
We should override the compareTo() method in the Media class to sort the media objects by title (alphabetically). If two titles are equal, we then compare them by cost (higher cost comes first).

Example logic:
@Override
public int compareTo(Media other) {
    int titleCompare = this.title.compareToIgnoreCase(other.title);
    if (titleCompare != 0) return titleCompare;
    return Float.compare(other.cost, this.cost); // descending cost
}
3. Can we have two ordering rules of the item (by title then cost and by cost then title) if we use this Comparable interface approach?
No, the Comparable interface only allows us to define one natural ordering using compareTo().
If we want multiple sorting rules, like "title then cost" or "cost then title", we should use the Comparator interface instead, which allows flexible and dynamic sorting logic outside the class.

4. Suppose the DVDs have a different ordering rule from the other media types, that is by title, then decreasing length, then cost. How would you modify your code to allow this?
To support a different ordering rule for DVDs:

Do not rely solely on the compareTo() in the Media class.

Instead, write a custom Comparator for DigitalVideoDisc, like this:

Comparator<DigitalVideoDisc> dvdComparator = Comparator
    .comparing(DigitalVideoDisc::getTitle, String.CASE_INSENSITIVE_ORDER)
    .thenComparing(Comparator.comparingInt(DigitalVideoDisc::getLength).reversed())
    .thenComparing(Comparator.comparingDouble(DigitalVideoDisc::getCost));
When sorting a list of DVDs, pass this comparator into Collections.sort().
